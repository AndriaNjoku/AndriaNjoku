# Hi, I'm Andria Njoku 👋🏿

**Software engineer · Android specialist · Founder of [Karma Politics](https://karmapolitics.co.uk)**

I build mobile products and the systems behind them. My work spans civic accountability, practical AI tools and thoughtful interfaces—with a focus on making complicated information useful.

Android is my foundation. Recent work also takes me across React Native, backend services, data pipelines and desktop tooling, from early product experiments through implementation and release work.

## What I'm building

- **[Karma Politics](https://karmapolitics.co.uk)** — helping people understand UK parliamentary activity, follow their representatives and explore the evidence behind political claims. My work covers the Android experience, backend and data services, and an evolving shared React Native app for mobile and web.
- **Nudge by Notch** — tooling in development for supervising coding-agent workflows, reviewing activity and making engineering checks easier to inspect.
- **[OmiDaemon](https://github.com/AndriaNjoku/OmiDaemon)** — an open-source experiment turning wearable transcripts into useful notes, tasks and follow-up drafts, with Obsidian integration.
- **Product experiments** — exploring visual approaches to social discovery and document-centred property workflows, including React Native interfaces and document extraction with human review. These remain prototypes.

Across these projects, I'm interested in where AI helps people understand information and take useful action, and where clear permissions, review and good interface design matter most.

## Engineering focus

- **Mobile & interface craft:** Kotlin, Jetpack Compose, React Native, Expo, TypeScript, accessible interaction and animation.
- **Services & data:** Kotlin/Ktor, Python, SQL, REST and GraphQL, ingestion and source-linked information.
- **Delivery & tooling:** AWS, Docker, GitHub Actions, automated checks and developer workflows.

I care about clear evidence, understandable software and giving people control over their information.
