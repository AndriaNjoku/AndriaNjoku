# Andria Njoku

**Senior Software Engineer · Founder of [Karma Politics](https://karmapolitics.co.uk)**

I build software that helps people understand what's happening, make better decisions and stay in control. My interests span AI infrastructure, useful AI applications and the craft of making an interface feel right.

My foundation is Android, Kotlin and Jetpack Compose. These days, I work across mobile, web, backend services and automation. The aim is the same: solve real problems with systems people can understand and trust.

## What I'm building

### [Karma Politics](https://karmapolitics.co.uk)
Tools to make UK parliamentary activity easier to follow and check against its sources. I'm building across the product, from the interfaces people use to the services that organise the underlying records.

*In development. Less “trust me.” More “show me the record.”*

### [Monzo Bot](https://github.com/AndriaNjoku/monzo-bot)
An unofficial, open-source Android budgeting companion built around transaction exports, category budgets and optional AI assistance. A personal project I'm building for myself and sharing with others.

*In development. Not affiliated with Monzo. AI features use the user's chosen provider and API key; exported data and cloud processing still deserve care.*

### [OmiDaemon](https://github.com/AndriaNjoku/OmiDaemon)
Open-source experiments in turning wearable transcripts into structured notes, tasks and follow-up drafts, with Obsidian integration.

*Experimental assistant tooling, not a finished autonomous service.*

## The wider vision

**Cyberpunk Monk** is a creative identity I'm exploring through fiction and visual work: embracing technology without giving up human judgement, creativity or the satisfaction of making things by hand.

That idea runs through my engineering too. I want technology to do useful work and leave us more room to think, create and live.
